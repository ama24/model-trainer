# model-trainer

A friendly, generic app for training YOLO models (detection, segmentation, classification, pose, rotated boxes).
You load a dataset, check its health, pick a base model from a dropdown, tweak as much or as little as you like,
then watch it train with pause/resume. Afterwards you evaluate the model, try it on your own images and export it.

**Status:** design phase. See [docs/DESIGN.md](docs/DESIGN.md).
